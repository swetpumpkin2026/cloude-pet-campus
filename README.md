校园流浪宠物位置记录与3D地图展示系统
----一个面向校园的流浪猫狗位置记录与可视化平台，目前处于早期开发阶段-----

1.项目背景：
学校里有一群热爱流浪猫狗的同学，但大家主要通过群聊交流信息，存在信息分散、位置描述不清、新同学难以融入等问题。本项目希望用技术手段解决这些问题：
记录校宠位置：方便同学投喂、查看状态，防止走丢
消除信息差：让各部门、各小群体之间的信息互通
搭建交流平台：未来计划提供领养、讨论、活动组织等功能

2.当前进展
已完成：
（1）2D 卫星地图展示
（2）随机标记点投放
（3）点击标记点弹出宠物信息（名称、状态、简短互动语）
（4）GitHub Pages 在线部署
在线预览：https://swetpumpkin2026.github.io/cloude-pet-campus/

技术栈：
HTML / CSS
